## 🐙 全新核心系统升级 (V0.3.0 Features)

### 1. 🌟 电影级 UnrealBloomPass HDR 泛光后处理
- 集成 Three.js 后处理合成管线（`EffectComposer + UnrealBloomPass + OutputPass`），赛博发光触手、生物吸盘与星云呈现极具质感的科幻柔和泛光。

### 2. ⚡ 维度能量子与触须反向动力学捕获 (Dimensional Quanta & IK Harvesting)
- 空间中随机漂浮着自发光的晶体维度能量子（Polyhedral Energy Quanta）。
- 8 条触须末端具有自主感知与反向动力学（IK Attraction）弯曲捕食能力，接近能量子时吸附吞噬并爆发璀璨的粒子星火！

### 3. 💨 仿生漏斗等离子墨水喷射 (Volumetric Ink & Plasma Jet)
- 触发冲击波（`Space` 或点击核心）时，头足外套膜剧烈舒张收缩，自仿生漏斗（Siphon）向后喷射出高密度的流体等离子烟云粒子，伴随剧烈镜头震颤与后坐力回弹！

### 4. 🎬 电影级自动航行纪录片模式 (Cinematic Odyssey Director)
- 快捷键 `C` 随时开启自动镜头调度系统：
  - **Shot 1**：头足发光复眼与量子神经环宏观微距特写
  - **Shot 2**：穿越 8 条起伏触须与浮游海洋雪的仰角追踪
  - **Shot 3**：俯瞰星系吸积盘与赛博母体网格的超宽广角轨道运镜
  - **Shot 4**：直穿外壳中枢的超维跃迁俯冲

### 5. 📖 机密标本图志与科研日志抽屉 (Specimen Codex Drawer)
- 快捷键 `T` 或点击右上角 `CODEX` 呼出侧滑半透明玻璃拟态图志：
  - 实时显示头足生物 **3 颗心脏心率**（Systemic Core Heart 56 BPM、两颗鳃心 Branchial Hearts 52 BPM）
  - 外套膜流体压强、发色基团激光态、已捕获能量子计数
  - 各跨尺度维度的详尽科幻世界观科研档案

### 6. 🔊 纯数学多声部音频合成器 2.0 (Zero-Asset Procedural Audio)
- **3 心脏搏动节律**：以深沉低频 Sine 波真实模拟头足纲三重心跳声。
- **五度相生律和弦琶音**：捕获能量子时自动弹奏泛音晶体乐音。
- **空间声相立体声定位**：音效随触手在左右声道的摆动实现动态声相平移。

## 🎮 操控全览 (Controls)

| 操作方式 | 功能说明 |
| :--- | :--- |
| **鼠标拖拽 (Drag)** | 360° 旋转观察视角 |
| **鼠标移动 (Pointer)** | 触手感知取向与双眼凝视追踪 |
| **滚轮 / 键盘 `1 - 4`** | 切换四大跨尺度维度（Quantum / Abyss / Cyber / Cosmic） |
| **空格键 (`Space`) / 核心** | 喷射等离子墨水云、触发神经奇点冲击波与镜头震颤 |
| **按键 `C` / 顶部按钮** | 开启 / 关闭电影级自动运镜航行模式 (Cinematic Odyssey) |
| **按键 `T` / 顶部按钮** | 呼出 / 收起标本生理档案与航海图志抽屉 (Specimen Codex) |
| **按键 `M` / 顶部按钮** | 开关实时生成式程序化音频合成器 |
| **右上角色彩球** | 实时切换生物荧光、虚空奇点、深渊金、太阳等离子发光基底 |

## 🚀 本地运行与构建

```bash
# 1. 安装依赖
npm install

# 2. 启动本地开发服务 (带热重载与 60FPS 极速预览)
npm run dev

# 3. 生产环境构建打包 (TypeScript + Vite)
npm run build

# 4. 预览打包静态应用
npm run preview
```
