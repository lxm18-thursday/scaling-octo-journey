# 🐙 Scaling Octo Journey (无限尺度八爪深空跃迁)

[![Build & Package Scaling Octo Journey](https://github.com/lxm18-thursday/scaling-octo-journey/actions/workflows/ci.yml/badge.svg)](https://github.com/lxm18-thursday/scaling-octo-journey/actions/workflows/ci.yml)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](https://opensource.org/licenses/MIT)

> **"From the deepest abyssal trenches to the edge of quantum cosmos — an 8-fold procedural cosmic odyssey."**
> 
> *《Scaling Octo Journey》* 是一个融合了生成式深海生物动力学、无限尺度空间变换（Powers of Ten）、赛博神经网与实时粒子合成的超视界 3D 沉浸式项目。

---

## 🌟 核心创意体系 (The Vision)

- **🐙 八爪跨尺度智体 (Octo Neural Core)**：
  - 8 条自适应反向运动学（IK Wave Physics）触须，分别映射 8 个维度。
  - 生物荧光发色基团（Chromatophore Emissive Matrix）与核心光环脉冲。
- **🌌 无限跨尺度跃迁 (Powers of 10 Scaling Journey)**：
  - **$10^{-15}\text{m} \sim 10^{-9}\text{m}$**：超维量子泡与微观生物粒子。
  - **$10^0\text{m} \sim 10^3\text{m}$**：深海热泉裂隙（Abyssal Trench）与生化浮游群。
  - **$10^6\text{m} \sim 10^{12}\text{m}$**：行星数字神经网与轨道网格矩阵。
  - **$10^{20}\text{m} \sim 10^{26}\text{m}$**：跨星系星云与宇宙弦织造。
- **🔊 实时程序化音效合成 (Web Audio Procedural Synth)**：
  - 每次尺度缩放、核心冲击波脉冲均通过数学谐波实时合成声效。

---

## 🚀 自动化构建与持续集成 (CI / CD Actions)

本项目内置 GitHub Actions 自动化编译打包工作流（`.github/workflows/ci.yml`）：

1. **自动依赖检测与语法校验** (`TypeScript + Vite`)
2. **云端无头构建与产物校验** (`npm run build`)
3. **自动打包与 Artifacts 发布**：每次 push 自动生成 `scaling-octo-journey-dist` 可执行打包产物
4. **GitHub Pages 自动化部署**（可选开启）

---

## 🛠️ 本地运行与构建

```bash
# 1. 安装依赖
npm install

# 2. 本地开发服务器 (热重载)
npm run dev

# 3. 生产环境编译打包
npm run build

# 4. 预览生产构建
npm run preview
```
