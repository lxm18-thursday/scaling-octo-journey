## 🌌 四重跨尺度维度系统 (4-Dimensional Biomes)

通过滚轮、顶部导航栏或快捷键 `1 - 4`，即可在以下 4 个数量级间无缝跃迁：

| 维度编号 | 维度代号 | 尺度等级 | 视觉与物理生态 |
| :--- | :--- | :--- | :--- |
| **01** | **QUANTUM FOAM** | $10^{-15} \text{ m}$ | **超维量子泡**：普朗克微观奇点、亚原子高能弦晶格与布朗抖动 |
| **02** | **ABYSSAL TRENCH** | $10^{1} \text{ m}$ | **深海渊裂**：生物荧光黑潮、洋流海洋雪浮游颗粒与热泉辉光 |
| **03** | **CYBER MATRIX** | $10^{9} \text{ m}$ | **矩阵中枢**：行星级数字神经网、霓虹赛博矩阵网格与信息流环 |
| **04** | **COSMIC NEBULA** | $10^{24} \text{ m}$ | **群星深空**：对数螺旋星系悬臂、跨星云吸积盘与超维引力透镜 |

## 🐙 核心特性 (Key Features)

- **生物荧光八爪智体 (Cyber Cephalopod Engine)**：
  - 8 条自适应反向动力学（IK Wave Dynamics）触手，每条具有 35 级铰接段与吸盘荧光矩阵。
  - 仿生头足纲喷气推进推进机制（Mantle Jet-Propulsion），头部舒张与收缩物理回弹。
  - 赛博神经环（Neural Rings）旋转折射与双眼光标动态追踪。
- **纯数学实时音频合成 (Zero-Asset Procedural Audio Synth)**：
  - 无需任何外部音频资源，通过 Web Audio API 动态合成：
    - 随着尺度高低自适应变频的深空次低音氛围无人机（Sub-bass Ambient Drone）
    - 尺度跃迁声呐脉冲（Sonar Ping）
    - 神经冲击波释放时的 Major 和弦琶音与低音冲击（Sub-Impact Arpeggio）
- **四大发色基团色彩方案 (Chromatophore Themes)**：
  - 🌟 **Bioluminescence** (荧光青/魅惑粉)
  - 🔮 **Singularity Void** (量子紫/深空蓝)
  - 👑 **Abyssal Gold** (深渊金/琥珀辉)
  - 🔥 **Solar Plasma** (太阳等离子/赤红熔火)
- **CI / CD 云端自动编译构建**：
  - 接入 GitHub Actions，每次 push 自动执行无头编译、产物完整性校验与打包上传。

## 🎮 操控指南 (Controls)

| 操作方式 | 功能说明 |
| :--- | :--- |
| **鼠标拖拽 (Drag)** | 旋转环绕观察视角 |
| **鼠标移动 (Pointer)** | 触须与头足眼睛方向追踪 |
| **滚轮 / 键盘 `1 - 4`** | 切换四大跨尺度维度（Quantum / Abyss / Cyber / Cosmic） |
| **核心点击 / 空格键 (`Space`)** | 释放神经奇点冲击波（Neural Pulse Discharge）与声效 |
| **键盘 `M` / 顶部按钮** | 开关实时生成式程序化音频 |
| **右上角色彩球** | 实时切换头足生物发色基团配色方案 |

## 🚀 本地运行与构建

```bash
# 1. 安装依赖
npm install

# 2. 启动本地开发服务 (带热重载)
npm run dev

# 3. 生产环境构建打包 (TypeScript + Vite)
npm run build

# 4. 本地预览打包产物
npm run preview
```
